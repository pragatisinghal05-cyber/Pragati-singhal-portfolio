# Pragati Singhal — Portfolio Website

## Files
- `index.html` — main portfolio page
- `style.css` — responsive styling
- `script.js` — mobile menu and back-to-top button
- `resume.pdf` — optional: add Pragati's actual resume PDF here

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a GitHub account if needed.
2. Create a new repository, e.g. `pragati-singhal-portfolio`.
3. Upload `index.html`, `style.css`, `script.js` and optional `resume.pdf`.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** branch and `/ (root)`, then Save.
7. After deployment, GitHub will show the live Pages URL.

## Before submission
- Replace the `PS` circle with your own photo if desired.
- Replace the GitHub/LinkedIn placeholder links with your actual profile URLs.
- Add your real resume as `resume.pdf`.
- Test every navigation link and the live website on mobile.
